Optional AI and international transfers

Data and purpose. Home type, climate, selected equipment and system types, existing task names and language to suggest recurring upkeep tasks. If you enter your own text, leave out details that identify a person.

How we route AI requests

If AI sharing is on and you request a result from a feature in this app that uses direct processing, Alpha Loop sends the inputs listed above directly to OpenAI OpCo, LLC in the United States. The first route uses OpenAI’s GPT-6 Luna through the direct API.

If the direct service is temporarily unavailable or reaches a rate or usage limit, OpenRouter handles eligible requests using GPT-6 Luna. If the Luna attempt through OpenRouter encounters a retryable error or a response-length limit, a text-only request can fall back to DeepSeek V4.1 Flash 1017 through OpenRouter. DeepSeek inference hosts.

앱별 처리 항목

데이터처리 목적·위치보관·삭제
작업, 완료일·이력, 메모, 알림, 체크리스트기기에서 계산·저장한다. OS 알림은 로컬 예약이다. 사용자가 파일을 공유할 때만 선택한 앱으로 내보낸다.앱 삭제 흐름이 로컬 목록·설정·내보내기 임시 파일을 정리한다. 사용자가 공유한 외부 사본은 수신처에 남는다.
언어, 집 유형, 기후, 설비 종류, 기존 작업 이름별도 AI 동의 후 추천을 요청할 때만 Cloudflare Worker로 보낸다. Worker는 위 AI 요청의 전송 조건을 적용한다. 주소와 정비 이력은 전송하지 않는다. 작업 이름에 개인 정보가 포함될 수 있다.Worker 원장은 계정별 사용량·비용·재생 결과를 관리한다. 입력 캐시는 같은 계정·작업·정책의 입력 해시에만 적용한다(최대 30일). 기기에 응답 표시를 기다리는 결과가 남을 수 있다.
익명 UUID·기기 증명·세션, 이전 계정의 소유권 증명인증, 기존 구매 귀속, 중복 혜택 방지. Worker 기기 증명과 서명 영수증은 OS 보안 저장소에 보관한다.탈퇴 후 계정 접근 권한을 삭제한다. 사용한 무료 혜택을 이어가기 위한 서명 영수증·서버 해시는 유지된다.
구매·복원·구독 자격스토어와 RevenueCat이 거래를 처리한다. 앱은 검증된 UUID, 스토어 상품과 서버 자격을 대조한다.거래 기록은 각 처리자의 정책에 따른다. 앱 탈퇴 후에도 구독 해지는 스토어에서 별도로 진행한다.
결과 신고사용자가 선택한 사유, 메모, 신고한 항목, 유형·기후, 언어, 결과 ID 및 독립 신고 UUID를 전송한다.확인 전에는 기기에서 재시도하고 접수 후 로컬 대기를 해제한다. 탈퇴 시 계정 신고를 삭제한다.
제품 이벤트·오류Worker에는 고정 이벤트 이름만 보낸다. 오류에는 정제한 패키지 프레임, 지문, 앱 버전, 플랫폼이 포함된다.Worker의 앱 활동 정리, 집계·백업 보관 기간과 외부 처리자 정책을 운영자가 확인한다.
