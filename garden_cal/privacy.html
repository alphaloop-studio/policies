Privacy notice for the older service version

Device data

The app stores frost dates, plant lists and reminders on the device. You control the copies you export or share. Your operating system’s backup settings may apply.

Optional AI

If you choose the feature and give permission, Cloudflare receives a crop name of up to 40 characters and your language.

When it sends a request for AI processing, Cloudflare first tries OpenAI (GPT-6 Luna) directly. If a temporary failure, usage quota, or rate limit prevents processing on that route, Cloudflare may send the request to OpenAI (GPT-6 Luna) through OpenRouter. If the OpenRouter Luna attempt encounters a retryable failure or a response length limit, Cloudflare may send a text-only request to DeepSeek (V4.1 Flash 1017) through OpenRouter as the final fallback.

Direct OpenAI requests use store=false to turn off storage of the Chat Completions API response for later retrieval. OpenAI's default abuse monitoring logs may contain submitted content and responses. OpenAI keeps these logs for up to 30 days by default and may keep them longer where required by law or reasonably necessary to prevent harm to its services or others. Organization-level Zero Data Retention (ZDR) requires separate approval from OpenAI. See OpenAI API data controls. On the OpenRouter route, we apply the routing filters zdr: true, data_collection: "deny". OpenRouter and the selected model provider apply their processing and retention terms to requests on that route.

The app service records fingerprints, results, quotas and costs. Successful matching inputs can be replayed for up to 30 days when the app has input caching enabled. Account deletion is a separate operation.

Account, purchases, reports and diagnostics

Cloudflare processes the anonymous account ID, device authentication proofs and security information. Google Play or Apple processes payment where supported. RevenueCat connects store purchase status to the app account. Reports you submit can contain a selected result, reason and optional text. Usage and diagnostic reports can include an event name, error fingerprint, selected code frames, platform and app version. This GardenCal configuration contains the Google Mobile Ads SDK and test configuration. It does not request ads.

Retention and deletion

Deleting the account removes associated data from active app storage. Hashed receipts and associated free-use counts can remain to prevent reactivation and repeat free grants. Store and payment records follow the processors' retention policies. Remove exported copies from their storage locations.

앱별 처리 항목

Cloudflare는 AI 처리를 위해 전송할 때 OpenAI(GPT-6 Luna)에 먼저 직접 요청해요. 일시적 장애, 사용량 한도 또는 호출 속도 제한으로 직접 처리할 수 없으면 OpenRouter를 통해 OpenAI(GPT-6 Luna)에 요청할 수 있어요. OpenRouter 경유 Luna 요청에 재시도 가능한 오류가 나거나 응답 길이 제한에 걸리면, Cloudflare는 텍스트만 포함된 요청에 한해 OpenRouter 경유 DeepSeek(V4.1 Flash 1017)를 최종 대체 경로로 사용할 수 있어요.

OpenAI에 직접 요청할 때 store=false를 설정해 Chat Completions API 응답을 나중에 조회하기 위한 저장을 꺼요. OpenAI의 기본 남용 모니터링 로그에는 제출한 내용과 응답이 포함될 수 있어요. 로그는 기본적으로 최대 30일 보관하며, 법률상 필요하거나 OpenAI 서비스 또는 제3자의 안전을 위해 합리적으로 필요한 경우 더 오래 보관할 수 있어요. 조직 차원의 Zero Data Retention(ZDR)은 OpenAI의 별도 승인이 필요한 설정이에요. 자세한 내용은 OpenAI API 데이터 관리 안내를 확인하세요. OpenRouter 경유 요청에는 라우팅 필터 zdr: true, data_collection: "deny"를 적용해요. 이 경로의 요청에는 OpenRouter와 선택된 모델 제공사의 처리·보관 조건이 적용돼요.

데이터전송 조건과 수신처목적과 보관
서리일, 텃밭 목록, 완료 기록, 알림, 온보딩 답변기기에서 계산하고 예약한다. 사용자가 내보낸 백업은 사용자가 고른 앱에만 전달한다. GPS를 요청하지 않는다.기기 삭제 시 초기화한다. 사용자가 외부에 복사한 백업은 별도다.
익명 ID와 기기 증명온라인 빌드에서 Cloudflare가 발급하고 기기의 보호 저장소에 보관한다. Worker는 IP에 기반한 단기 가입 제한을 적용한다.인증, 부정 사용 방지, 비용 통제. 서버에는 기기 증명의 해시가 남는다. RevenueCat에 동일 사용자 ID를 전달한다.
AI 입력과 결과사전 동의 후 작물 이름 최대 40자와 언어를 Cloudflare Worker로 보낸다. Worker는 위 AI 요청의 전송 조건을 적용한다.일정 추정. Worker는 사용자별 요청 지문과 응답을 성공 시 최대 30일 재사용하고 모델, 토큰, 가명 사용량과 비용을 기록한다.
결과 신고사용자가 신고한 작물의 표시 일정, 사유, 메모 최대 300자, 언어와 모델을 Cloudflare에 보낸다. Worker 결과 ID와 별개의 신고 UUID를 함께 보내며, 전송 전 기기 대기열에 저장해 모호한 응답에도 같은 신고로 재시도한다.AI 결과 검토. 사용자별 서버 신고는 탈퇴 범위다.
앱 사용과 진단고정 Ev 이벤트명만 전송한다. ErrorReporter는 앱 버전, OS 종류, 정제된 코드 프레임과 오류 지문을 보낸다.사용 흐름 분석과 안정성. 작물명, 구매 영수증, 원본 예외 메시지는 이벤트 속성에서 제외한다. 별도 분석 선택 설정은 없다.
구매Play/App Store와 RevenueCat이 영수증과 구매 내역을 처리하고 Worker가 구독 권한을 조회한다.구매·복원·권한 확인. 계정 삭제와 SDK 로그아웃 후에도 구독은 스토어에서 별도로 해지한다.
광고스테이징에서 광고를 요청하지 않는다. Google Mobile Ads SDK와 테스트 ID가 패키지에 포함된다.출시 빌드의 병합된 권한과 SDK 초기화·수집 여부를 Play 신고 전 확인한다. 보상 광고를 채택하면 UMP, 광고 식별자·상호작용·진단 항목을 다시 검토한다.
