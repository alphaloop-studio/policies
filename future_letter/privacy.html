Device data

The app stores letters, drafts and reminders on the device. You control the copies you export or share. Your operating system’s backup settings may apply.

Optional AI and international transfers

This privacy policy update takes effect on 2026-11-28 (Korea time). This section covers Sealday (FutureLetter)’s optional AI on Alpha Loop Commons. In Android version code 5, AI requests covered by the existing in-app disclosure and AI sharing choice use OpenRouter.

Data and purpose. Opening horizon, selected themes and tone, previously used prompts and language to suggest writing questions. Letter titles, body text and calendar dates stay on the device.

How we route AI requests

If AI sharing is on and you request a result from a feature in this app that uses direct processing, Alpha Loop sends the inputs listed above directly to OpenAI OpCo, LLC in the United States. The first route uses OpenAI’s GPT-6 Luna through the direct API.

If the direct service is temporarily unavailable or reaches a rate or usage limit, OpenRouter handles eligible requests using GPT-6 Luna. If the Luna attempt through OpenRouter encounters a retryable error or a response-length limit, a text-only request can fall back to DeepSeek V4.1 Flash 1017 through OpenRouter. DeepSeek inference hosts.

Recipients and retention

Direct OpenAI. When the request needs new processing, Alpha Loop’s Cloudflare Worker sends it over HTTPS to OpenAI to generate the requested result. OpenAI OpCo, LLC is at 1455 3rd Street, San Francisco, CA 94158, United States. The global API can process data in the United States and in other countries listed by OpenAI. privacy@openai.com · OpenAI data processing terms · Processing locations.

For direct Chat Completions, store=false turns off saving the response for later retrieval. OpenAI’s default abuse-monitoring logs can include prompts, responses and related metadata for up to 30 days. OpenAI may retain data longer if required by law or reasonably necessary for safety. Zero Data Retention requires separate approval and configuration. API data is excluded from model training by default unless the API customer opts in. OpenAI API data controls.

Via OpenRouter. When you request a result on this route and new processing is needed, Alpha Loop sends the inputs above via HTTPS through its Cloudflare Worker to OpenRouter, Inc. (United States). To generate the result, OpenRouter forwards them to an eligible inference host for the chosen model. The host can vary by request and may process data outside Korea. support@openrouter.ai · GPT-6 Luna inference hosts · Cloudflare data processing terms.

For this route we ask OpenRouter to select endpoints eligible for zero-retention routing that disallow provider data collection. OpenRouter and the selected host apply their terms, including any applicable retention of operational metadata, or retention for legal or safety reasons. OpenRouter privacy policy · OpenRouter data processing terms.

App service. Where result replay is enabled, Alpha Loop’s service uses a request fingerprint and can provide a successful result for the same input for up to 30 days. Usage, cost and submitted reports follow the app’s own retention and deletion rules.

Your choices

In the Android versions listed above, the AI sharing choice applies to all optional AI features. Decline the in-app prompt to keep AI sharing off. To withdraw, turn off AI sharing in Settings. That stops all future AI transfers. Information already sent follows the recipient’s retention and deletion rules. You can continue writing and keeping letters. privacy@alphaloop.dev.

Account, purchases, reports and diagnostics

Cloudflare processes the anonymous account ID, device authentication proofs and security information. Google Play or Apple processes payment where supported. RevenueCat connects store purchase status to the app account. Reports you submit can contain a selected result, reason and optional text. Usage and diagnostic reports can include an event name, error fingerprint, selected code frames, platform and app version. This configuration does not serve ads.

Retention and deletion

Deleting the account removes associated data from active app storage. Hashed receipts and associated free-use counts can remain to prevent reactivation and repeat free grants. Store and payment records follow the processors' retention policies. Remove exported copies from their storage locations.

AI 요청의 전송 순서

이 앱에서 AI 공유를 켜고 직접 처리 대상 기능을 요청하면 Alpha Loop는 위에 안내한 입력을 미국 OpenAI OpCo, LLC에 직접 보내요. 먼저 직접 API로 OpenAI의 GPT-6 Luna를 사용해요.

직접 서비스에 일시 장애가 생기거나 호출·사용 한도에 도달하면 경유가 가능한 요청은 OpenRouter를 통해 GPT-6 Luna로 처리해요. OpenRouter를 통한 Luna 요청에 재시도 가능한 오류나 응답 길이 제한이 생기면 텍스트 전용 요청만 OpenRouter를 통해 DeepSeek V4.1 Flash 1017로 추가 대체할 수 있어요. DeepSeek 추론 호스트.

이전받는 자와 보관

OpenAI 직접 처리. 새 처리가 필요하면 Alpha Loop의 Cloudflare Worker가 OpenAI에 HTTPS로 요청을 보내 결과를 만들어요. OpenAI OpCo, LLC의 주소는 미국 1455 3rd Street, San Francisco, CA 94158이에요. 글로벌 API는 미국 및 OpenAI가 공개한 다른 국가에서도 정보를 처리할 수 있어요. privacy@openai.com · OpenAI 데이터 처리 조건 · 처리 지역 목록.

직접 Chat Completions의 store=false는 나중에 다시 조회할 응답의 저장을 꺼요. OpenAI는 기본 남용 모니터링 로그에 프롬프트·응답·관련 메타데이터를 최대 30일 보관할 수 있어요. 법령 준수 또는 안전상 합리적으로 필요한 경우 더 오래 보관할 수 있어요. Zero Data Retention은 별도의 승인과 설정이 필요해요. API 데이터는 기본적으로 모델 학습에서 제외되며 API 고객이 선택한 경우에는 학습에 쓰일 수 있어요. OpenAI API 데이터 제어.

OpenRouter 경유. 이 경로로 결과를 요청해 새 처리가 필요하면 Alpha Loop는 위 입력을 Cloudflare Worker를 통해 OpenRouter, Inc.(미국)에 HTTPS로 보내요. OpenRouter는 결과를 만들기 위해 해당 모델의 조건을 충족하는 추론 호스트로 전달해요. 호스트는 요청별로 달라질 수 있고 한국 밖에서 처리할 수 있어요. support@openrouter.ai · GPT-6 Luna 추론 호스트 · Cloudflare 데이터 처리 조건.

이 경로에는 제공자 데이터 수집을 거부하고 무보관 대상으로 분류된 엔드포인트를 선택하도록 OpenRouter에 요청해요. OpenRouter와 선택된 호스트는 운영 메타데이터 보관 및 법적 의무나 안전상 필요한 보관에 각자의 조건을 적용해요. OpenRouter 개인정보처리방침 · OpenRouter 데이터 처리 조건.

앱 서비스. 결과 재생을 지원하는 기능에서 Alpha Loop 서비스는 요청 지문을 사용해 같은 입력의 성공 결과를 최대 30일 동안 다시 제공할 수 있어요. 사용량·비용·직접 제출한 신고에는 앱의 보관 및 삭제 기준을 적용해요.

거부와 철회

위에 적힌 Android 버전의 AI 공유 선택은 선택형 AI 전체에 적용돼요. 앱의 AI 동의 화면에서 거부하면 공유를 켜지 않아요. 철회하려면 설정에서 AI 공유를 꺼 주세요. 이후 모든 AI 요청의 전송이 중단돼요. 이미 보낸 정보는 수신자의 보관·삭제 기준을 따라요. 편지 작성과 보관는 계속 이용할 수 있어요. privacy@alphaloop.dev.

앱별 처리 항목

데이터수신처와 목적보관·삭제
편지 제목·본문·작성일·열람일, 초안과 알림기기 전용 저장소와 로컬 알림. 알림에는 편지 내용이 없다.기기에서 삭제한다. 직접 내보낸 JSON은 봉인된 편지도 평문으로 포함한다. 사용자가 저장·공유한 사본은 그 위치에서 삭제해야 한다.
익명 사용자 ID, 기기 증명Cloudflare 인증과 계정 복구. 이전 계정은 기존 세션으로 소유권을 증명한다. 결제 시 같은 ID를 RevenueCat에서 사용한다.증명은 기기 보안 저장소에 둔다. 서버 삭제 후 기기 세션을 지우며 무료 혜택 승계를 위한 서명 영수증을 보존한다.
구독·구매 내역Google Play 또는 App Store와 RevenueCat이 결제·복원을 처리한다. Worker에서 권한을 재확인한다.계정 삭제와 스토어 구독 해지는 별개다. 스토어·결제 처리자의 보관 조건을 게시 정책에 반영한다.
AI 입력과 출력, 사용량별도 동의 후 언어·열람 기간·주제·톤·이미 사용한 질문을 Cloudflare Worker로 보낸다. Worker는 위 AI 요청의 전송 조건을 적용한다. 앱은 편지 제목·본문·날짜를 포함하지 않는다.동일 계정·작업·입력의 성공 결과를 최대 30일 재생한다. Worker가 사용량과 공급자 비용을 기록한다. 기기의 미확인 결과는 복구 또는 삭제 때까지 보관한다.
신고한 생성 결과, 사유·메모Cloudflare에 결과 ID와 별도 신고 UUID를 전송한다. 사용자가 직접 제출한 메모에 개인정보가 있을 수 있다.확인 전에는 기기 큐에 보관한다. 서버의 계정별 신고는 삭제 대상이다.
앱 상호작용, 오류 진단Cloudflare에 고정 이벤트명, 앱 버전, OS, 오류 지문과 필터링한 코드 위치를 전송한다. 편지, 프롬프트, 원본 오류 메시지, 결제 토큰을 이벤트 속성으로 전송하지 않는다.계정과 연결된 기록은 삭제한다. 식별자를 제외한 비용·운영 집계는 남을 수 있다.
