Optional AI and international transfers

This privacy policy update takes effect on 2026-11-28 (Korea time). This section covers Marklore (Antique Scanner)’s optional AI on Alpha Loop Commons. In Android version code 2, AI requests covered by the existing in-app disclosure and AI sharing choice use OpenRouter.

How we route AI requests

If AI sharing is on and you request a result from a feature in this app that uses direct processing, Alpha Loop sends the inputs listed above directly to OpenAI OpCo, LLC in the United States. The first route uses OpenAI’s GPT-6 Luna through the direct API.

If the direct service is temporarily unavailable or reaches a rate or usage limit, OpenRouter handles eligible requests using GPT-6 Luna. The Worker sends photos only to GPT-6 Luna, at most once on each permitted route. If the Luna attempt through OpenRouter encounters a retryable error or a response-length limit, a text-only request can fall back to DeepSeek V4.1 Flash 1017 through OpenRouter. DeepSeek inference hosts.

이 앱에서 AI 공유를 켜고 직접 처리 대상 기능을 요청하면 Alpha Loop는 위에 안내한 입력을 미국 OpenAI OpCo, LLC에 직접 보내요. 먼저 직접 API로 OpenAI의 GPT-6 Luna를 사용해요.

직접 서비스에 일시 장애가 생기거나 호출·사용 한도에 도달하면 경유가 가능한 요청은 OpenRouter를 통해 GPT-6 Luna로 처리해요. 사진은 GPT-6 Luna로만 보내며, Worker는 사용 가능한 경로마다 최대 한 번 전송해요. OpenRouter를 통한 Luna 요청에 재시도 가능한 오류나 응답 길이 제한이 생기면 텍스트 전용 요청만 OpenRouter를 통해 DeepSeek V4.1 Flash 1017로 추가 대체할 수 있어요. DeepSeek 추론 호스트.

앱별 처리 항목

항목전송 시점과 용도보관·삭제
익명 사용자 ID와 기기 증명Cloudflare가 세션을 발급한다. 이관 시 기존 사용자 증명을 Worker에서 검증한 뒤 같은 UUID를 채택한다. RevenueCat도 이 ID를 사용한다.기기 보안 저장소에 세션과 증명을 보관한다. 탈퇴 후 서명된 혜택 영수증을 남겨 같은 설치에서 무료 혜택을 다시 발급하지 않도록 한다.
사진·사용자 콘텐츠명시적 동의 뒤 선택한 사진 최대 세 장을 한 JPEG로 합쳐 Cloudflare Worker에 보낸다. 텍스트 재분석 요청에는 이전 AI 결과와 사용자가 입력한 설명을 보낸다. 두 요청 모두 분류와 언어를 포함하며 위 전송 조건을 적용한다.원본 사진·컬렉션·메모는 기기의 앱 저장소에 있다. Worker는 결과 재생을 위해 성공 결과를 최대 30일 재사용한다. 기기에서는 재시도 키와 응답을 별도로 보관한다. 설정에서 동의를 철회할 수 있다.
구독·구매 기록Google Play 또는 Apple과 RevenueCat이 거래를 처리한다. 앱은 스토어 가격·체험 조건 및 서버 확인 권한을 사용한다.카드번호를 수집하지 않는다. 탈퇴와 구독 해지는 별개이며 스토어에서 해지한다. 처리자의 거래 기록에는 별도 보관 정책이 적용된다.
사용량·결과 신고Worker가 성공한 무료 호출 수, 일일 한도, 토큰과 비용을 집계한다. 신고에는 서버 결과 ID, 신고 UUID, 선택 사유를 보낸다.신고 실패 시 기기에 저장해 재전송한다. 원격 삭제 확인 후 로컬 큐도 정리한다. 사용자 원장과 별도로 식별자를 포함하지 않는 비용 집계가 남는다.
앱 사용·진단고정 이벤트 이름, 정제된 스택 프레임, 플랫폼, 앱 버전을 Worker에 보낸다. 설정에서 사용 통계를 끌 수 있다.사진·설명·원문 예외·토큰을 분석 페이로드에 넣지 않는다. 계정 삭제 시 서버의 사용자 이벤트·오류가 삭제된다.
외부 공유·가격 검색사용자가 공유 시트를 열어 결과·사진·CSV의 수신자를 선택한다. eBay 검색 버튼은 선택한 물건의 검색어를 eBay에 전달한다.앱 내 임시 CSV와 공유 캐시는 계정 정리 대상이다. 사용자가 외부에 저장하거나 전달한 사본은 수신처에 남을 수 있다.
