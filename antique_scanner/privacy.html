Privacy notice for the older service version

Device data

The app stores collection, photos and notes on the device. You control the copies you export or share. Your operating system’s backup settings may apply.

Optional AI

If you choose the feature and give permission, Cloudflare receives a single JPEG made from up to three selected photos for recognition. For text-only refinement, Cloudflare receives the description you enter and the earlier result. Both requests include the category and language.

If you separately consent to direct OpenAI processing, Cloudflare first sends the AI request directly to OpenAI (GPT-6 Luna). If a temporary failure, usage quota, or rate limit prevents processing on that route, Cloudflare may send the request to OpenAI (GPT-6 Luna) through OpenRouter.

If you have given only the existing OpenRouter consent, Cloudflare sends the AI request first to OpenAI (GPT-6 Luna) through OpenRouter. With this consent, all model requests go exclusively through OpenRouter.

OpenAI is the only model provider for a request that includes a photo. With separate direct consent, Cloudflare can send each photo request at most once directly to OpenAI and at most once through OpenRouter. With existing OpenRouter consent only, Cloudflare can send each photo request at most once through OpenRouter. In either case, if the OpenRouter Luna attempt encounters a retryable failure or a response length limit, Cloudflare may use DeepSeek (V4.1 Flash 1017) through OpenRouter as the final fallback for text-only refinement.

If you decline AI processing, the app blocks transmission of AI requests.

Direct OpenAI requests use store=false to turn off storage of the Chat Completions API response for later retrieval. OpenAI's default abuse monitoring logs may contain submitted content and responses. OpenAI keeps these logs for up to 30 days by default and may keep them longer where required by law or reasonably necessary to prevent harm to its services or others. Organization-level Zero Data Retention (ZDR) requires separate approval from OpenAI. See OpenAI API data controls. On the OpenRouter route, we apply the routing filters zdr: true, data_collection: "deny". OpenRouter and the selected model provider apply their processing and retention terms to requests on that route.

The app service records fingerprints, results, quotas and costs. Successful matching inputs can be replayed for up to 30 days when the app has input caching enabled. Account deletion is a separate operation.

Account, purchases, reports and diagnostics

Cloudflare processes the anonymous account ID, device authentication proofs and security information. Google Play or Apple processes payment where supported. RevenueCat connects store purchase status to the app account. Reports you submit can contain a selected result, reason and optional text. Usage and diagnostic reports can include an event name, error fingerprint, selected code frames, platform and app version. This configuration does not serve ads.

Retention and deletion

Deleting the account removes associated data from active app storage. Hashed receipts and associated free-use counts can remain to prevent reactivation and repeat free grants. Store and payment records follow the processors' retention policies. Remove exported copies from their storage locations.

앱별 처리 항목

OpenAI 직접 처리에 별도로 동의하면 Cloudflare는 AI 요청을 OpenAI(GPT-6 Luna)에 먼저 직접 보내요. 일시적 장애, 사용량 한도 또는 호출 속도 제한으로 직접 처리할 수 없으면 OpenRouter를 통해 OpenAI(GPT-6 Luna)에 요청할 수 있어요.

기존 OpenRouter 동의만 있으면 Cloudflare는 OpenRouter를 통해 OpenAI(GPT-6 Luna)에 AI 요청을 먼저 보내요. 이 경우 모델 요청은 모두 OpenRouter를 통해서만 전송해요.

사진 요청의 모델 제공사는 OpenAI로 한정해요. OpenAI 직접 처리에 별도로 동의하면 사진 요청 한 건을 OpenAI에 직접 최대 한 번, OpenRouter를 경유해 OpenAI에 최대 한 번 보내요. 기존 OpenRouter 동의만 있으면 사진 요청 한 건을 OpenRouter를 통해 최대 한 번 보내요. 두 경우 모두 OpenRouter 경유 Luna 요청에 재시도 가능한 오류가 나거나 응답 길이 제한에 걸리면, Cloudflare는 텍스트 재분석 요청에 한해 OpenRouter 경유 DeepSeek(V4.1 Flash 1017)를 최종 대체 경로로 사용할 수 있어요.

AI 처리를 거부하면 앱은 AI 요청 전송을 차단해요.

OpenAI에 직접 요청할 때 store=false를 설정해 Chat Completions API 응답을 나중에 조회하기 위한 저장을 꺼요. OpenAI의 기본 남용 모니터링 로그에는 제출한 내용과 응답이 포함될 수 있어요. 로그는 기본적으로 최대 30일 보관하며, 법률상 필요하거나 OpenAI 서비스 또는 제3자의 안전을 위해 합리적으로 필요한 경우 더 오래 보관할 수 있어요. 조직 차원의 Zero Data Retention(ZDR)은 OpenAI의 별도 승인이 필요한 설정이에요. 자세한 내용은 OpenAI API 데이터 관리 안내를 확인하세요. OpenRouter 경유 요청에는 라우팅 필터 zdr: true, data_collection: "deny"를 적용해요. 이 경로의 요청에는 OpenRouter와 선택된 모델 제공사의 처리·보관 조건이 적용돼요.

항목전송 시점과 용도보관·삭제
익명 사용자 ID와 기기 증명Cloudflare가 세션을 발급한다. 이관 시 기존 사용자 증명을 Worker에서 검증한 뒤 같은 UUID를 채택한다. RevenueCat도 이 ID를 사용한다.기기 보안 저장소에 세션과 증명을 보관한다. 탈퇴 후 서명된 혜택 영수증을 남겨 같은 설치에서 무료 혜택을 다시 발급하지 않도록 한다.
사진·사용자 콘텐츠명시적 동의 뒤 선택한 사진 최대 세 장을 한 JPEG로 합쳐 Cloudflare Worker에 보낸다. 텍스트 재분석 요청에는 이전 AI 결과와 사용자가 입력한 설명을 보낸다. 두 요청 모두 분류와 언어를 포함하며 위 전송 조건을 적용한다.원본 사진·컬렉션·메모는 기기의 앱 저장소에 있다. Worker는 결과 재생을 위해 성공 결과를 최대 30일 재사용한다. 기기에서는 재시도 키와 응답을 별도로 보관한다. 설정에서 동의를 철회할 수 있다.
구독·구매 기록Google Play 또는 Apple과 RevenueCat이 거래를 처리한다. 앱은 스토어 가격·체험 조건 및 서버 확인 권한을 사용한다.카드번호를 수집하지 않는다. 탈퇴와 구독 해지는 별개이며 스토어에서 해지한다. 처리자의 거래 기록에는 별도 보관 정책이 적용된다.
사용량·결과 신고Worker가 성공한 무료 호출 수, 일일 한도, 토큰과 비용을 집계한다. 신고에는 서버 결과 ID, 신고 UUID, 선택 사유를 보낸다.신고 실패 시 기기에 저장해 재전송한다. 원격 삭제 확인 후 로컬 큐도 정리한다. 사용자 원장과 별도로 식별자를 포함하지 않는 비용 집계가 남는다.
앱 사용·진단고정 이벤트 이름, 정제된 스택 프레임, 플랫폼, 앱 버전을 Worker에 보낸다. 설정에서 사용 통계를 끌 수 있다.사진·설명·원문 예외·토큰을 분석 페이로드에 넣지 않는다. 계정 삭제 시 서버의 사용자 이벤트·오류가 삭제된다.
외부 공유·가격 검색사용자가 공유 시트를 열어 결과·사진·CSV의 수신자를 선택한다. eBay 검색 버튼은 선택한 물건의 검색어를 eBay에 전달한다.앱 내 임시 CSV와 공유 캐시는 계정 정리 대상이다. 사용자가 외부에 저장하거나 전달한 사본은 수신처에 남을 수 있다.
