Device data

The app stores closet, wear records and style preferences on the device. You control the copies you export or share. Your operating system’s backup settings may apply.

Optional AI

If you choose the feature and give permission, Cloudflare receives a resized clothing photo with metadata removed and the selected language. A configured weather feed receives requests for the selected city.

When it sends a request for AI processing, Cloudflare first tries OpenAI (GPT-6 Luna) directly. If a temporary failure, usage quota, or rate limit prevents processing on that route, Cloudflare may send the request to OpenAI (GPT-6 Luna) through OpenRouter. OpenAI is the only model provider for a request that includes a photo. Cloudflare can send it at most once directly to OpenAI and at most once through OpenRouter. The DeepSeek fallback is limited to text-only requests.

Direct OpenAI requests use store=false to turn off storage of the Chat Completions API response for later retrieval. OpenAI's default abuse monitoring logs may contain submitted content and responses. OpenAI keeps these logs for up to 30 days by default and may keep them longer where required by law or reasonably necessary to prevent harm to its services or others. Organization-level Zero Data Retention (ZDR) requires separate approval from OpenAI. See OpenAI API data controls. On the OpenRouter route, we apply the routing filters zdr: true, data_collection: "deny". OpenRouter and the selected model provider apply their processing and retention terms to requests on that route.

The app service records fingerprints, results, quotas and costs. Successful matching inputs can be replayed for up to 30 days when the app has input caching enabled. Account deletion is a separate operation.

Account, purchases, reports and diagnostics

Cloudflare processes the anonymous account ID, device authentication proofs and security information. Google Play or Apple processes payment where supported. RevenueCat connects store purchase status to the app account. Reports you submit can contain a selected result, reason and optional text. Usage and diagnostic reports can include an event name, error fingerprint, selected code frames, platform and app version. This configuration does not serve ads.

Retention and deletion

Deleting the account removes associated data from active app storage. Hashed receipts and associated free-use counts can remain to prevent reactivation and repeat free grants. Store and payment records follow the processors' retention policies. Remove exported copies from their storage locations.

앱별 처리 항목

Cloudflare는 AI 처리를 위해 전송할 때 OpenAI(GPT-6 Luna)에 먼저 직접 요청해요. 일시적 장애, 사용량 한도 또는 호출 속도 제한으로 직접 처리할 수 없으면 OpenRouter를 통해 OpenAI(GPT-6 Luna)에 요청할 수 있어요. 사진을 포함한 요청은 건마다 OpenAI에 직접 최대 한 번, OpenRouter를 경유해 OpenAI에 최대 한 번 보내요. 사진 요청의 모델 제공사는 OpenAI로 한정해요. DeepSeek 대체 경로는 텍스트만 포함된 요청에 한정돼요.

OpenAI에 직접 요청할 때 store=false를 설정해 Chat Completions API 응답을 나중에 조회하기 위한 저장을 꺼요. OpenAI의 기본 남용 모니터링 로그에는 제출한 내용과 응답이 포함될 수 있어요. 로그는 기본적으로 최대 30일 보관하며, 법률상 필요하거나 OpenAI 서비스 또는 제3자의 안전을 위해 합리적으로 필요한 경우 더 오래 보관할 수 있어요. 조직 차원의 Zero Data Retention(ZDR)은 OpenAI의 별도 승인이 필요한 설정이에요. 자세한 내용은 OpenAI API 데이터 관리 안내를 확인하세요. OpenRouter 경유 요청에는 라우팅 필터 zdr: true, data_collection: "deny"를 적용해요. 이 경로의 요청에는 OpenRouter와 선택된 모델 제공사의 처리·보관 조건이 적용돼요.

정보수신처와 목적보관·선택권
옷장·착용 기록·스타일 답변기기에서 코디를 계산한다. 수동 입력에는 AI가 필요 없다.기기 설정에서 삭제한다. 내보낸 백업은 사용자가 선택한 위치에 남는다.
선택한 사진·앱 언어동의한 태깅 요청 한 건의 사진과 앱 언어만 Cloudflare Worker에 보낸다. Worker는 위 사진 요청의 전송 조건을 적용한다. 카메라·갤러리 사진을 축소하고 위치 등 메타데이터를 제거한다.앱은 옷장 사진과 미완료 요청을 기기에 둔다. Worker는 재생용 입력 해시와 성공 결과를 최대 30일 보관한다. 제공사 계약상 보관 조건은 운영자가 확인한다. AI는 설정에서 끌 수 있다.
익명 사용자·기기 증명Worker가 UUID와 복구 증명을 발급한다. 서버에는 기기 증명 해시, 기기 보안 저장소에는 세션을 보관한다. 기존 계정은 검증 후 같은 UUID로 연결한다.삭제 후 혜택 영수증·가명 삭제 표식과 사용한 무료 혜택 수가 남는다. UUID만으로 구매자 계정을 연결하지 않는다.
구매·구독스토어와 RevenueCat에 구매 내역과 같은 사용자 UUID를 연결한다. Worker가 entitlement를 확인한다.스토어 해지·환불과 RevenueCat 보관 정책은 별도다. 앱은 카드 정보를 받지 않는다.
사용 통계·진단Worker에 고정 이벤트명, 정제한 오류 유형·스택, 버전·플랫폼을 전송한다. 태그 내용·사진·URL·토큰을 이벤트 속성으로 보내지 않는다.설정에서 통계와 오류 전송을 끌 수 있다. 원격 계정 기록은 삭제 흐름에 포함된다.
AI 사용량·비용Worker가 예약·실제 토큰·공급자 시도·예산을 집계한다.비대상 및 사용할 수 없는 결과는 사용자 할당량을 반환한다. 발생한 공급자 비용과 불확실한 실패의 예약 비용 상한은 공유 정책을 따른다.
자발적 신고원래 태그·사유·메모·언어·모델 정보, 서버 결과 ID(발급된 경우), 신고별 UUID를 Worker에 보낸다.서버 접수 전까지 기기 대기열에 보관한다. 삭제 시 서버 신고도 지운다.
